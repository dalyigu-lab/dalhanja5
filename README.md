# 달달맘한자 5급 모의고사

대한검정회 한자급수자격검정 5급 기출(80~96회, 15회분 750문항)을 분석해서
열 때마다 새로운 50문항 모의고사를 실제 시험지 모양으로 만들어 주는 연습 앱입니다.

- 새 시험지 받기 → 풀기 → 빨간 펜 채점 → 오답노트 → 오답 재시험
- 실제 기출 15회분 그대로 풀기
- 시험지·정답해설·오답노트 인쇄
- 결과를 카톡·문자로 엄마에게 보내기

주소: https://dalyigu-lab.github.io/dalhanja5/

※ 85·88·95·96회는 공식 정답지가 없어 직접 풀이한 예상 정답을 사용했습니다.
